# Puff-It-BAR-999

A polished static storefront for the PIB Electronic Delivery Systems brand.

## Overview
This repository contains a responsive, marketing-focused landing page built with plain HTML, CSS, and JavaScript. It is designed to present the product catalog in a modern, premium format while keeping the project lightweight and easy to deploy.

## Project structure
- `index.html` — overall page structure and content
- `styles.css` — visual design, layout, responsive behavior, and theme styling
- `script.js` — age gate logic, product tab switching, and FAQ interactions

## How to run locally
Open `index.html` in a browser, or serve the folder with any static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes
- The site uses a browser-only age gate to simulate the required verification flow.
- No build tools, package manager, or framework are required.
- The project is intentionally lightweight for quick hosting on GitHub Pages or any static hosting provider.
